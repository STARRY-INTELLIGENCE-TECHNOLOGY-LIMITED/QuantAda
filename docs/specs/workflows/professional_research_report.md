# 专业研报工作流

本文件定义面向投资人、合作方、家办、私募或资管机构的专业研报/策略说明/技术白皮书生成规范。

适用范围:
1. 投资人版策略说明书。
2. 技术白皮书或尽调版说明。
3. 合作模式备忘录。
4. 业绩复盘、策略月报、阶段性验证报告。

本规范只描述通用写作与交付约束，不绑定任何具体实体、策略、路径、账户、参数或绩效数字。

## 1. 文档定位

1. 先明确读者是谁，再决定详略:
   - 普通投资者需要收益来源、风险边界、回撤解释、下一步验证方式。
   - 专业投资者需要参数口径、样本区间、成本假设、回测与实盘差异。
   - 私募/资管尽调需要可复现链路、账户对账、风控机制、容量与滑点假设。
2. 文档应服务投资沟通和尽调，不展示作者与 AI 的协作过程。
3. 不把历史回测包装成收益承诺。所有历史绩效都应标注口径、区间、成本和风险提示。
4. 标题不应过度突出框架名、项目代号或内部代号。标题优先体现策略类别、资产范围、研究目的或验证阶段。

## 2. 推荐文档结构

### 2.1 投资人版策略说明书
1. 重要声明。
2. 策略定位与适合资金。
3. 核心绩效摘要。
4. 收益来源与策略逻辑。
5. 参数训练与避免过拟合。
6. 回测结果、净值曲线、回撤曲线、月度收益分布。
7. 风险因素与实盘验证计划。
8. 合作事项边界与尽调清单。
9. 结语。

### 2.2 技术白皮书/尽调版
1. 重要声明与阅读范围。
2. 策略框架总览。
3. 核心公式、因子定义与交易规则。
4. 参数空间、训练窗口、评分函数与样本外验证。
5. 回测结果、年度窗口、月度收益分布。
6. 执行链路、券商状态、委托、拒单、T+1、告警和对账。
7. 风险因素、容量和后续验证。
8. 开源、权属、系统能力或其他可公开资料。

### 2.3 合作模式备忘录
1. 重要声明。
2. 当前阶段定位。
3. 可讨论合作路径。
4. 验证期安排。
5. 资金与资源用途边界。
6. 沟通顺序。
7. 合作原则。

## 3. 行文原则

1. 使用中国大陆投资者熟悉的简体中文研报语法。
2. 可保留常见金融缩写，例如 ETF、Sharpe、PF、Calmar、T+1、K 线；不要为熟悉缩写写生硬解释。
3. 少用英文标题和英文术语。必须使用英文时，应确保该词在金融或量化语境下常见。
4. 避免口语化:
   - 避免“这套、这个、很多、很关键、是不是、怎么、哪里、明天涨跌、一天两天、稍微”等。
   - 用“本系统、本策略、较多、核心在于、是否、如何、来源、短期涨跌、短期噪声、一定幅度”等替代。
5. 避免 AI 味解释:
   - 不写“本文后续会”“为便于理解”“这里保留方法”“建议将图表输出到”“请回填”等过程性语句。
   - 不写客户无需感知的内部说明，例如本机路径、命令、文件夹、占位符、旧版本资料来源、AI 辅助分析。
6. 避免指令感过强:
   - 用“审阅、核查、复核、完成验证后”替代“先阅读、再阅读、请查看”。
7. 避免别扭的尽调用语:
   - 少用“证据、证据链”。优先使用“核验材料、记录、资料、留痕、对账资料、复现记录”。
8. 避免过度否定和防御式表达:
   - 合规声明中的“不构成、不承诺、不保证”可以保留。
   - 正文中尽量用正向表述，例如“资金适配边界”优于“不适合的资金”。
9. 避免过度自夸:
   - 不写“领先、革命性、确定性、稳定赚钱、稳赚、闭眼买”等承诺或营销化表述。
   - 技术力通过公式、流程、参数、验证、风控和复现链路体现。
10. 保持面向客户:
   - 客户关心收益来源、风险边界、可复现性、实盘可执行性、合作路径。
   - 不展示作者调试过程、工具选择、临时目录、命令行细节或与 AI 的讨论痕迹。

## 4. 数据与绩效表达

1. 所有绩效数字必须绑定区间:
   - 起止日期。
   - 初始资金和期末资金。
   - 总收益、年化收益、最大回撤、Sharpe、Calmar、PF、胜率、交易数等。
2. 回测、训练、样本外、实盘必须分开写，不能混用。
3. 若使用训练结果和最新回测结果，应明确它们属于不同口径。
4. 不用单个高年化数字作为唯一卖点。必须同步写回撤、盈亏因子、交易次数、胜率、平均盈亏比和月度收益分布。
5. 允许保留重要具体数值。为了避免空泛，关键绩效表不应过度脱敏。
6. 对强收益月份应说明其阶段性和市场环境，避免暗示每月稳定盈利。
7. 对负收益月份应正常呈现，解释其与趋势切换、震荡、风险偏好变化或策略退化的关系。
8. 历史绩效段落应避免重复堆叠旧口径。若存在新旧结果，以最新、最可复核口径为主。

## 5. 图表使用

1. 投资人版至少应包含:
   - 绩效摘要表。
   - 净值曲线。
   - 回撤曲线。
   - 月度收益热力图。
2. 技术白皮书可增加:
   - 年度固定窗口。
   - 参数重要性。
   - 参数稳定性或平行坐标。
   - 交易分布、容量与滑点测算。
3. 图表正文不能只说“见图”。应说明图表揭示的投资含义:
   - 收益是否集中。
   - 回撤是否连续恶化。
   - 月度收益是否依赖少数月份。
   - 策略是否具备跨市场差异。
4. 不在正式交付文档中出现本机路径、截图操作命令或待补图说明。
5. 对外版本不保留“图表文件未加载、占位图、待回填”等字样。

## 6. 合作与合规表达

1. 合作备忘录应讨论路径和边界，不应像募集说明书。
2. 常用表述:
   - “当前阶段定位为策略和系统验证阶段。”
   - “完成小规模、可审计、可复盘的真实账户曲线后，再讨论规模扩大。”
   - “涉及资金安排时，应完成法律、合规、税务和投资者适当性审阅。”
3. 避免表达:
   - “保证收益、承诺回撤、确定盈利、资金马上进来、闭环收割”等。
4. “合作原则”比“底线原则”更适合对外文件。
5. “核验材料”比“证据链”更适合客户语境。

## 7. 排版与交付

1. 正文统一首行缩进 2 字符；标题后第一段也应缩进，除非使用特殊摘要框、图表、表格或页眉页脚。
2. 表格标题、列名和图注应专业、简洁。
3. PDF 交付前必须重新编译，并检查:
   - 图表是否加载。
   - 页眉页脚是否正常。
   - 表格是否溢出。
   - 目录、引用、页码是否更新。
   - 是否仍有占位符或本地路径。
4. 对外交付文件名应清晰，例如:
   - 投资人版策略说明书。
   - 技术白皮书/尽调版。
   - 合作模式备忘录。

## 8. 最终自查关键词

交付前应扫描并人工复核以下词语。命中不代表一定错误，但需要确认是否适合对外发布:

1. 内部过程类:
   - 回填、待补、占位、TODO、命令、本机、路径、截图、AI、旧论文、草稿、临时、这里、后续再。
2. 口语类:
   - 这套、这个、很多、很关键、是不是、怎么、哪里、明天、一天两天、稍微、跑出、先读、再读。
3. 别扭尽调用语:
   - 证据、证据链、材料充分、底线。
4. 过度承诺类:
   - 稳赚、保证、确定性收益、无风险、低风险高收益、稳赚不赔。
5. 生硬提示类:
   - 为便于、如需、可根据、建议将、图表建议、请补充、请回填。

## 9. 交付口径

最终回复应只说明:
1. 产出文件位置。
2. 已完成的核心调整。
3. 已验证事项。
4. 未验证或仍需客户提供的材料。

不要在最终交付说明中复述大量写作过程，也不要暴露内部中间文件、命令或与 AI 的协作细节。
